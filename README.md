Developed an end-to-end Legal NLP and Generative AI pipeline for 7,973 Indian and UK court judgments, covering data validation, leakage-safe splitting, long-document preprocessing, supervised fine-tuning, LLM evaluation, and Retrieval-Augmented Generation. Implemented token-aware chunking and Sentence Transformer MPNet-based semantic alignment, achieving a 95.99% sentence-match rate and creating 15,333 SFT training samples. Fine-tuned Qwen3-8B using 4-bit NF4 QLoRA, PEFT, SFT, and BF16, optimizing only 43.6M parameters (~0.53%) and improving held-out ROUGE-2 by ~33% over the base model. Designed a Hybrid RAG retrieval system using FAISS dense retrieval, BM25 sparse retrieval, Reciprocal Rank Fusion, and Cross-Encoder reranking over 170K+ legal chunks, achieving 96.7% Recall@5, 0.893 MRR@10, and 0.914 nDCG@10.
